# Logging

Paths are relative to the webv2 `src/` directory.

Platform Logging is the one recorder for application and project events. `createLogger` binds a source (namespace, area, optional project, widget and operation identity); a runtime passes account scope it captured so writes after that lifetime are discarded; module-level loggers stay unbound. Entries normalized once at ingestion into immutable JSON-safe snapshots: errors keep name, message, stack, cause and status/code; credential-like keys redacted; URL queries and fragments stripped; depth, collection, string and 8 KiB entry ceilings marked explicitly. History is account-wide, memory-only, in three bounded buffers (warn and above, lower severities, timings) so verbose traffic cannot evict problems; closed projects keep entries until eviction or account cleanup. Publication coalesced per microtask; clears and account transitions publish synchronously and restore default capture settings. Workbench owns preference-to-config mapping and diagnostics panel; App applies saved preferences before React mounts, installs uncaught-error and router catch reporting, and keeps config in step with active account. Each handled terminal failure has one reporting owner: Workbench store records reported errors, widget failures, autosave outcomes and queue item transitions; persistence runtime records an exit checkpoint that did not save, since it outlives editor; transport and coordinator events are debug breadcrumbs.
