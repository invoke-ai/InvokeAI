# Canvas font fixtures

These tiny TrueType files are self-authored browser-test fixtures generated with
fontTools. They contain a single rectangle glyph for `A`; `custom-axis.ttf` is
variable with `wght` and `TEST` axes, while `custom-axis-wide.ttf` is a static
wide instance used to verify pinned output metrics. They contain no third-party
font data or licensing restrictions.
