# Fonts

Paths are relative to the webv2 `src/` directory.

Fonts owns its authenticated catalog, managed-library UI, and browser font-registration lifetime behind `@features/fonts`. App composes session runtime; Canvas gets a font-resolution port and owns text geometry, rendering, and output readiness. Persisted text references and project-file remapping stay in Workbench. Launchpad font previews and Canvas share the same account lifetime; font binaries and browser registration names are not project state. Browser registry admits at most 64 faces and 128 MiB of font input data, including faces being parsed. Active references are protected from eviction; if they exhaust budget, further loads fail until references are released. This bounds retained input, not browser-specific decoded font memory. Canvas reconciles active references only when document forests or text draft source change.

Font runtime composition and project-file option state ride existing shared route chunk. Catalog transport, Fonts page, and project-file option dialogs load on demand. Missing-font recovery loads only for documents with custom references. Locale asset plugin serves font-library strings as a separate namespace in development and production, loaded when library or recovery UI opens; source translations stay in canonical locale files. Text tool controls load when selected; their shared Canvas/Layer form and interaction dependencies stay grouped to avoid extra widget-activation requests. Catalog query keys have a lightweight public entry so invalidating an imported font does not pull transport into startup.
