Invoke has two translation projects: the documentation is translated on [Crowdin](https://crowdin.com/project/invoke), and the app on [Weblate](https://hosted.weblate.org/engage/invokeai/). Both are free to join, and your work reaches the project through automated pull requests, so you don't need to touch the repository.

## Documentation

The docs are translated into German, Spanish and Hindi in our [Crowdin project](https://crowdin.com/project/invoke). Sign in to Crowdin, join the project, pick a language and translate pages and interface strings there.

- Pages that aren't translated yet show the English page with a notice, so every language has the full docs from the start.
- Every translated page has a **Translate this page** link with the page tools (in the right-hand column on wide screens, at the end of the page on small ones) that opens the Crowdin project.
- The guides and reference pages are translated. The developer and contributor docs stay in English.
- Translations come back as a pull request from Crowdin, which maintainers review before they go live. Please don't edit the `de`, `es` or `hi` directories in the repository by hand: Crowdin overwrites them on its next sync.

To suggest a new language, ask on [Discord](https://discord.gg/ZmtBAhwWhy).

## App

The app's interface is translated in our [Weblate project](https://hosted.weblate.org/engage/invokeai/). [Weblate](https://weblate.org/) is a free and open-source translation service, provided at no cost to open-source projects like Invoke.

Sign in with your GitHub account (Google and several other accounts work too), select a language and then the Web UI component. From there you can browse and translate strings from English into your language; Zen mode offers a simpler translation view.

Your changes are attributed to you in the automated pull request; you don't need to do anything else.
