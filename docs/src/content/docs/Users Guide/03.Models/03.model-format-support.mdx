InvokeAI recognizes a model's format from the file itself, so you install every build the same way. This page
lists which formats load for which model. What each format is, and how it behaves in memory, is explained under
[Quantized formats](/users-guide/models/model-families/#quantized-formats). Sizes, starter models and measured
speeds are on each family's own page.

**Legend:** ✓ loads · ✗ not supported · **R** refused at install with a message naming the reason · – no such
build exists

- **int8** means ComfyUI's `int8_convrot` (`int8_tensorwise`) builds. **nvfp4** and **fp8 scaled** mean ComfyUI's
  checkpoint layouts; other exports of the same schemes (AWQ, ModelOpt) are refused.
- **GGUF** covers the llama.cpp types (Q4_0 through Q8_0, the K-quants, BF16). ComfyUI-GGUF's `Q8_CR` files load
  for Krea-2 only and are refused for every other model.
- Wan 2.1, Wan Animate, S2V, Fun-Control and VACE builds are refused, as are LTX-2.0/2.3 files.

Quantized VAE files (fp8, int8, nvfp4) are refused for every family.
