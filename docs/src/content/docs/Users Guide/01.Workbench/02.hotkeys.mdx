Most commands in Invoke have a keyboard shortcut, and you can change any of them. This page explains where shortcuts work, how to change them, and lists every default.

In the tables, <kbd>Mod</kbd> means <kbd>Ctrl</kbd> on Windows and Linux and <kbd>Cmd</kbd> on macOS. On macOS, <kbd>Alt</kbd> is the <kbd>Option</kbd> key. Invoke shows each shortcut with your platform's key names.

## Where shortcuts work

- **App** shortcuts work anywhere in the workbench.
- **Panel** shortcuts (Canvas, Workflows, Viewer, Gallery) work only while that panel has keyboard focus. Click in a panel, or move focus to it, to give its keys priority. The center panel has focus when a project opens, and gets it back when a focused window docks or closes. The Viewer shortcuts belong to the **Preview** panel.
- When a panel shortcut uses the same key as an App shortcut, the panel's shortcut wins while that panel has focus, and the App shortcut works everywhere else. For example, <kbd>T</kbd> selects the Text tool on the Canvas and collapses the left panel elsewhere.
- While you type in a text field, single-key shortcuts do nothing so your typing is never interrupted. Shortcuts that make sense while writing a prompt still work there: Invoke, Invoke Front, Invoke To Other Destination, Focus Prompt, the prompt history and prompt weight keys, Open Project Switcher, Open Settings, the command palette, and the region and widget focus keys.
- While a dialog is open, only the command palette shortcut works.
- An open menu or list keeps its own arrow keys, <kbd>Enter</kbd>, <kbd>Esc</kbd>, <kbd>Space</kbd> and letter keys.
- A bare <kbd>Space</kbd> or <kbd>Enter</kbd> on a focused button or tile always presses it, whatever the shortcut. A focused slider or radio group likewise keeps its arrow keys, <kbd>Home</kbd> and <kbd>End</kbd>.
- Some shortcuts, such as the Canvas's <kbd>Mod</kbd>+<kbd>1</kbd> zoom, are also browser shortcuts. They work only when the browser passes the keys to the page.

The **Shortcuts** chip in the status bar lists the keys for whatever has focus, including Canvas pointer gestures and hold keys that are not customizable, such as holding <kbd>C</kbd> for the frame tool.

## Changing shortcuts

Open **Settings** (<kbd>Mod</kbd>+<kbd>,</kbd>, or the app menu) and choose **Keyboard shortcuts**. You can also choose **Keyboard Shortcuts** in the [command palette](#app), or **Keyboard shortcut settings** in the status bar's **Shortcuts** chip.

The **Hotkeys** list groups every shortcut under App, Canvas, Workflows, Viewer and Gallery, whether or not that panel is in your layout. **Search hotkeys** filters the list by command name or default key. Your shortcuts are saved with your account and apply in every project.

<Steps>
1. Click a key chip on a row to change it. The chip reads **Press keys**: press the new combination. Press <kbd>Esc</kbd> to stop recording without changing the chip, or click the trash button to remove that key.
2. Click **+** (**Add hotkey**) to give the command another key. A command can have several.
3. Click the check mark (**Save hotkey edit**) to keep the change, or **×** (**Cancel hotkey edit**) to discard it.
</Steps>

- **Disable** removes every key from a command. The row then reads **Disabled**.
- A dot next to a command's name marks a shortcut that differs from its default. The **Reset hotkey** button on the row returns it to the default; **Reset all**, at the top of the list, resets every shortcut.

Invoke checks each change before you save it:

- **Conflicts with …** (in red) means another command already uses that key where this one works, so the key would do two things at once. The check mark stays disabled until you choose another key or change the other command first.
- **Duplicate binding in this hotkey** means the same key is listed twice on one row.
- **Takes this key from … while … has focus** and **… takes this key while … has focus** (in yellow) mean a panel shortcut and an App shortcut share the key. This is allowed: each still works in its own place, as described in [Where shortcuts work](#where-shortcuts-work).

## App

These work anywhere in the workbench.

| Keys | Command | What it does |
| --- | --- | --- |
| <kbd>Mod</kbd>+<kbd>K</kbd> | Open Command Palette | Opens or closes the command palette, even while you type or a dialog is open |
| <kbd>Mod</kbd>+<kbd>Enter</kbd> | Invoke | Queues the active route |
| <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd> | Invoke Front | Queues ahead of your pending items |
| <kbd>Mod</kbd>+<kbd>Alt</kbd>+<kbd>Enter</kbd> | Invoke To Other Destination | Queues once with results sent to the other destination (Gallery instead of Canvas, or Canvas instead of Gallery). The saved route does not change. |
| <kbd>Shift</kbd>+<kbd>X</kbd> | Cancel Queue Item | Cancels the item that is running |
| <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>X</kbd> | Cancel all queue items | Cancels every unfinished item, after you confirm |
| <kbd>Alt</kbd>+<kbd>A</kbd> | Focus Prompt | Opens Generate and puts the cursor in the prompt |
| <kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>Alt</kbd>+<kbd>↓</kbd> | Prompt History Prev / Prompt History Next | Steps through your prompt history |
| <kbd>Ctrl</kbd>+<kbd>↑</kbd> / <kbd>Ctrl</kbd>+<kbd>↓</kbd> | Prompt Weight Up / Prompt Weight Down | Raises or lowers the attention weight at the cursor in a prompt field. Works only when the selected model reads attention syntax; <kbd>Ctrl</kbd> is Control on macOS too. |
| <kbd>Mod</kbd>+<kbd>P</kbd> | Open Project Switcher | Opens the project switcher |
| <kbd>Mod</kbd>+<kbd>,</kbd> | Open Settings | Opens Settings |
| <kbd>1</kbd> | Open Generate | Shows the Generate panel |
| <kbd>2</kbd> | Open Canvas | Shows the Canvas in the center |
| <kbd>3</kbd> | Open Upscale | Shows the Upscale panel |
| <kbd>4</kbd> | Open Workflow editor | Shows the Workflow editor in the center |
| <kbd>5</kbd> | Open Model Manager | Opens the Model Manager |
| <kbd>6</kbd> | Open Queue | Shows the Queue panel |

### Layout and focus

| Keys | Command | What it does |
| --- | --- | --- |
| <kbd>T</kbd> or <kbd>O</kbd> | Toggle Left Panel | Collapses or expands the left panel |
| <kbd>G</kbd> | Toggle Right Panel | Collapses or expands the right panel |
| <kbd>F</kbd> | Toggle Panels | Collapses or expands all side and bottom panels at once |
| <kbd>Z</kbd> | Toggle Preview | Swaps the Preview into or out of the center |
| <kbd>Mod</kbd>+<kbd>Alt</kbd>+<kbd>Z</kbd> | Undo layout change | Undoes the last change to the layout |
| <kbd>Mod</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo layout change | Redoes the layout change you undid |
| <kbd>Alt</kbd>+<kbd>1</kbd> to <kbd>Alt</kbd>+<kbd>4</kbd> | Select Compose Preset, Select Edit Preset, Select Video Preset, Select Workflow Preset | Switches to that built-in layout preset |
| <kbd>Alt</kbd>+<kbd>Shift</kbd>+arrow keys (<kbd>Ctrl</kbd>+<kbd>Cmd</kbd>+arrow keys on macOS) | Focus Region Left, Right, Up, Down | Moves keyboard focus to the neighbouring region of the workbench |
| <kbd>Alt</kbd>+<kbd>Page Up</kbd> / <kbd>Alt</kbd>+<kbd>Page Down</kbd> | Select Previous Widget / Select Next Widget | Shows the previous or next panel in the focused region |

**Revert layout to saved preset**, **Save Layout Preset** and **Show widgets** have no default keys; assign them in Settings if you use them often. See [Guided tour](/users-guide/workbench/introduction/) for layouts and presets.

### Staging bar

When the staging bar under the Canvas has focus, its own keys apply instead of the Canvas's, and they can't be changed:

| Keys | What it does |
| --- | --- |
| <kbd>←</kbd> / <kbd>→</kbd> | With more than one result, steps to the previous or next result |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Discards the selected result |

Arrow keys never nudge a layer while focus is in the staging bar.

## Gallery

These work while the Gallery has focus. See [Gallery reference](/users-guide/gallery/gallery-reference/) for how selection works.

| Keys | Command | What it does |
| --- | --- | --- |
| Arrow keys, or <kbd>Alt</kbd>+arrow keys | Gallery navigation up, right, down, left | Moves to the next item and selects it |
| <kbd>Shift</kbd>+arrow keys | Extend gallery selection up, right, down, left | Extends the selection |
| <kbd>Mod</kbd>+arrow keys | Move gallery focus up, right, down, left without selecting | Moves focus without changing the selection |
| <kbd>Mod</kbd>+<kbd>A</kbd> | Select all gallery images on page | Selects every item on the page |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete gallery selection | Deletes the selected items |
| <kbd>R</kbd> | Remix | Recalls the selected image's settings, except the seed |
| <kbd>.</kbd> | Toggle gallery image star | Stars or unstars the selected items |

**Clear gallery selection**, **Add or remove the focused gallery item from the selection** and **Toggle gallery starred-only filter** have no default keys.

## Image Map

While the Image Map has focus, <kbd>Esc</kbd> runs **Clear cluster selection**. It is listed under App in Settings while an Image Map is open.
